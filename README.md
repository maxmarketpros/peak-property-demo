# Peak Property Electric — peakpropertyelectric.com

Static site for Peak Property Electric LLC (Skokie, IL), hosted on Netlify
(project `peakpropertyelectric`). Netlify serves the committed HTML as-is —
there is **no CI build step**.

**Pretty URLs:** all internal links, canonicals, OG tags, JSON-LD, and the
sitemap use extensionless URLs (`/services/panel-upgrades`, not `.html`).
Netlify serves `/page` from `page.html` by default; enable **Pretty URLs**
on the Netlify project so `/page.html` also 301-redirects to `/page`.

## How the site is built

The deployable pages (`*.html` in the repo root, `services/`, `areas/`,
plus `sitemap.xml` and `robots.txt`) are **generated** by a small
zero-dependency Node script and committed to git.

**Never hand-edit the generated pages.** Edit the sources under `build/`,
then regenerate:

```
node build/build.mjs
```

and commit both the `build/` changes and the regenerated pages.

## What lives where

| Path | What it is |
|---|---|
| `build/templates/layout.html` | Page shell (head, topbar, nav, footer, sticky call button) |
| `build/templates/nav.html`, `footer.html`, `topbar.html` | Shared chrome — edit once, applies to all 34 pages |
| `build/templates/quote-section.html` | LeadConnector quote-form section used on subpages |
| `build/templates/service-page.html`, `area-page.html` | Templates for the 16 service and 13 area pages |
| `build/content/*.html` | Hand-written bodies for the root pages (index, services, our-work, reviews, areas, 404) |
| `build/data/site.json` | Phone, email, license #, tagline, domain, footer link lists — contact info is edited **here only** |
| `build/data/services.json`, `areas.json` | Full per-page content for service/area pages (generated by the assemble scripts below) |
| `build/data/gallery.json` | The Our Work gallery manifest (src, label, alt, dimensions) |
| `build/assemble-services.mjs`, `assemble-areas.mjs` | Rebuild services.json/areas.json from drafted copy + metadata (only needed when rewriting page copy wholesale) |
| `assets/css/site.css`, `assets/js/site.js` | The one shared stylesheet and script |
| `photos/brand/` | Real van + crew photos (web-sized) |
| `photos/work/` | Web-sized job photos used by the gallery and pages |
| `photos/client-photos/` | Original client photography (source files; not all referenced) |

## Common edits

- **Change phone/license/email/footer links:** edit `build/data/site.json`, run the build.
- **Add a gallery photo:** resize it (`magick in.jpg -auto-orient -resize "1200x1200>" -strip -quality 80 photos/work/name.jpg`), add an entry to `build/data/gallery.json` (src, label, cat, alt, w, h), run the build.
- **Add a nav item / change the dropdowns:** edit `build/templates/nav.html`, run the build.
- **Change copy on one service/area page:** edit that page's entry in `build/data/services.json` / `areas.json`, run the build.

## Local preview

`start-site.bat` (port 8000) or `node build/serve.mjs 8011` — a tiny static
server that resolves pretty URLs the way Netlify does (`/page` → `page.html`,
unknown paths → `404.html`). Plain `python -m http.server` no longer works
because internal links have no `.html` extension. Internal URLs are
root-relative, so pages must be viewed over HTTP, not file://.
